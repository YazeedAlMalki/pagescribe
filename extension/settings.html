Settings

PAGESCRIBE

Cache

Default: 24 hours. Expired results are unavailable immediately on access; cleanup runs while the extension is active and when it next opens.

Local OCR

Automatic PDF mode keeps usable native text and recognizes scanned pages. Force OCR replaces the text layer. Image rotation applies to JPG/PNG; PDF page rotation follows the PDF.

First download: English 12.02 MiB or Arabic 12.18 MiB (shared detector). Models use a separate 64 MiB cache. JavaScript, WASM and conversion stay on this device. Only model data is downloaded. Valid cached models work offline; missing or expired models require a connection.

Reading model cache…

Clearing models leaves results intact. An active session keeps its loaded models until its job ends. Cleanup runs on access and while the extension is active, not at an exact time while closed.

Reading cache…

Clears saved conversion results. Downloaded files and active inputs are retained. Abandoned source files expire after 24 hours.

Download directory

Chrome’s default download location

Chrome asks for folder access. You may need to grant it again in a new session. Existing files are preserved with numbered names.

“Download & Open” saves the file and opens a Markdown text preview in a browser tab.

Parallel batches

Up to 8 workers, with a queue for additional files. Requires 4+ GB device RAM; 8+ GB is recommended. Large files may wait for memory reservations to become available.

Processing stays in a dedicated extension tab. Keep it open until the batch finishes. Reopen an interrupted batch from the popup to resume unfinished files.
