# PageScribe logo

A white folded page and diagonal fountain pen on forest green. The mark is independent of Microsoft branding and is distributed under this project's MIT license.

The logo was generated with the built-in image-generation tool on October 6, 2026, then resized for use in the repository and extension. The final selected prompt was:

> Production PageScribe app icon. Use the supplied image only as a design reference for its white folded document and diagonal fountain pen silhouette. Recreate that same simple white document with a large diagonal pen nib cutout, centered on a COMPLETELY OPAQUE uniform solid forest green #285a44 square background extending fully to all four canvas edges. No transparent pixels anywhere, no rounded tile edges, no holes in the background. Large centered white symbol, about 65 percent of canvas width and 72 percent height. Precise flat graphic, two solid colors green and white, no text, no textures, no shading, no lighting, no gradients, no shadow. Single square icon. The nib cuts diagonally through the document and remains green, with a white circular slit detail. Preserve recognizable page corner fold.

Assets:

- [512-pixel logo](pagescribe-logo.png) for repository presentation.
- [Extension icons](../../extension/icons/icon-128.png) in 16, 32, 48 and 128 pixels, declared in the manifest and toolbar action.
- Popup, Settings and preview pages use the same mark.

PNG icon sizes follow [Chrome's manifest icon guidance](https://developer.chrome.com/docs/extensions/reference/manifest/icons).
